# Bundled ICC profile: ISO Coated v2 (ECI)

`ISOcoated_v2_eci.icc` is the “ISO Coated v2 (ECI)” profile published by
the European Color Initiative. It is built on the FOGRA39 characterization
data set, which represents commercial offset printing on gloss or matte
coated paper according to ISO 12647-2:2004/Amd 1, and is the default
destination profile for `ColorConverter.rgb_to_cmyk(method="icc")`.

## Source

- Publisher: European Color Initiative (ECI), www.eci.org
- Package: “ECI Offset 2009” (`eci_offset_2009.zip`), ECI downloads page,
  https://www.eci.org/doku.php?id=en:downloads
- Profile date: 2007-03-01
- The file is shipped unmodified. SHA-256:
  `128dc02f7246cc3807af0323695379f64151a8f27a587736acc59f8b6ce894b8`
